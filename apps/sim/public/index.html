Steps run top to bottom, then start over, forever. Each step is one stretch of running (or stopped) time.

Speed× 1.2 Variation± 3 % Timefor 10 min
Speed
How fast to cycle compared to the job's standard. ×1 = standard, ×1.2 = 20% faster, ×0.8 = 20% slower.
Variation
How much each cycle can randomly differ, so it looks like a real machine. ±3% on a 20 s standard = cycles between 19.4 and 20.6 s. 0 = every cycle exactly the same.
Time
How long this step runs before moving to the next one. Blank = stay on this step.

Example above: run 20% fast with a little variation for 10 minutes, then go to the next step. The buttons on each step (×1, +20%, −20%, Stop) fill in the speed for you.
